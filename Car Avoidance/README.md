# 🤖 ESP32 Obstacle Avoidance Robot

Robot autonom construit cu **ESP32** care detectează și evită obstacolele folosind un senzor ultrasonic **HC-SR04** montat pe un servomotor **SG90**.

### 🔧 Componente
- ESP32
- L298N
- 2 × motoare DC
- HC-SR04
- SG90
- Șasiu + roți
- Baterie

### ⚙️ Funcționare
Robotul merge înainte, detectează obstacolele, analizează stânga și dreapta și alege automat direcția cu mai mult spațiu.

### 🎛️ Control
Viteza motoarelor este controlată prin **PWM**, iar L298N gestionează direcția și alimentarea motoarelor.

### 👨‍💻 Autor
**Dany**
