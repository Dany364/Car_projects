# 🚗 ESP32 Robot Car Projects

A collection of robotic car projects developed using the **ESP32** platform. This repository serves as a central hub for all implementations based on the same robotic vehicle, each project showcasing different control methods, communication protocols, and functionalities.

---

## 📌 About

This repository contains multiple versions of an **ESP32-based robotic car**, ranging from beginner-friendly implementations to more advanced embedded applications. Each project focuses on a specific feature or communication technology while using the same hardware platform.

The objective is to demonstrate the versatility of the ESP32 in mobile robotics and provide practical examples for learning embedded systems, wireless communication, and motor control.

---

## 📂 Available Projects

- 📱 Bluetooth Controlled Car
- 📡 ESP-NOW Controlled Car
- 📶 Wi-Fi Controlled Car
- 🤖 Autonomous Robot Car *(Coming Soon)*
- 🚧 More projects coming soon...

---

## 🎯 Objectives

- Learn ESP32 programming
- Explore different wireless communication protocols
- Understand DC motor control
- Develop embedded robotics applications
- Create a modular platform for future robotic projects
