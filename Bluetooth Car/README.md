# 🚗 ESP32 Bluetooth Controlled Car

A beginner-friendly robotic car developed using **ESP32** and an **L298N motor driver**, controlled wirelessly through a Bluetooth mobile application. The project demonstrates the fundamentals of embedded systems, Bluetooth communication, and DC motor control.

---

## 📌 Project Overview

This project introduces the basic concepts of wireless robotics using the **ESP32** development board. The vehicle receives movement commands from a smartphone via Bluetooth and controls two DC motors through an L298N motor driver. An additional buzzer provides a horn function, making the project both interactive and easy to expand.

Designed as an introductory robotics project, it serves as a solid foundation for future improvements such as obstacle avoidance, autonomous navigation, or Wi-Fi control.
