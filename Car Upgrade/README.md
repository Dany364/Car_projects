# 🚗 Robot Mobil Autonom cu ESP32-CAM & Arduino Mega

Robot mobil multifuncțional, dezvoltat cu **Arduino Mega 2560** și **ESP32-CAM**, capabil de control manual prin Wi-Fi, monitorizare video și deplasare autonomă.

### ✨ Funcționalități
- 🎮 Control manual prin interfață web
- 🤖 Deplasare autonomă și evitare obstacole
- 📷 Streaming video în timp real
- 📡 Comunicație Wi-Fi și UART
- 📏 Măsurarea distanței cu HC-SR04
- 🚧 Detectarea obstacolelor cu senzori IR
- 💡 Iluminare automată cu LDR
- 🔊 Avertizare sonoră și vizuală

### 🧩 Hardware
**Arduino Mega 2560 • ESP32-CAM • L298N • HC-SR04 • 4× senzori IR • LDR • Servomotor • 4× motoare DC • LED-uri • Buzzer**

### 🔗 Arhitectură
**Utilizator → Wi-Fi → ESP32-CAM → UART → Arduino Mega → Senzori & Motoare**

> Proiect realizat în cadrul studiilor la Facultatea de Electronică, Telecomunicații și Tehnologia Informației – POLITEHNICA București.
